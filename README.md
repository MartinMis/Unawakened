# Unawakened
Unawakened is a simple roguelike endless runner (similar to legends such as temple run) with boss at the end of each stage. This game was developed as a part of 4 member team over the course of roughly
2 months. The game was developed in Unity using the C# programming language utilizing standard OOP and SOLID principles.

In its core the game is about guiding a sleepwalking creature through the halls of its house without it waking up. Bright lights, alarm clocks block your way as you try to outrun the monster under your
bed as well as the rising sun itself.

## Features
- Dynamically increasing difficulty
- Power-ups
- Various enemies and enviromental hazards
- Interactions with the enviroment
- Boss fight with puzzle elements
- Wake-up meter instead of health bar
